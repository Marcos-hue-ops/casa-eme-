# Fotos

Originais das fotos do site. Nada daqui é publicado direto: o comando
`npm run images` gera as versões WebP otimizadas em `src/assets/img/`
(ver README.md → "Fotos e imagens").

| Pasta | Conteúdo |
|---|---|
| `galeria/` | fotos de trabalhos (cabelo, unhas...). Viram imagens do site. |
| `ambiente/` | (criar quando houver) fotos do espaço — geram larguras maiores. |
| `referencias/` | prints usados como referência de marca e conteúdo. **Não são publicados.** |
| `nao-publicar/` | o que não pode ir ao site. **Nunca é publicado** (o teste trava). |

Dicas:

- Use o **arquivo original** da câmera ou do celular, não print de tela.
- Nomes descritivos, sem espaços nem acentos: `ambiente-recepcao.jpg`,
  `cabelo-mechas-01.jpg`.
- Sem marca-d'água, sem texto por cima (exceto rótulos de antes/depois).
- Só fotos reais da Casa EME — nada de banco de imagem ou imagem gerada por IA.

As quatro fotos atuais de `galeria/` vieram de prints do Instagram
@casaeme_moema (720 px de largura); os recortes que tiram a interface do
aplicativo estão em `tools/images.js`.
